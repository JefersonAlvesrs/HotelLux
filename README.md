# HotelLux 🏨

Site institucional responsivo de um **hotel de luxo fictício**, desenvolvido com HTML5, CSS3 e JavaScript puro.

## 🔗 Demonstração

Após publicar o repositório `HotelLux` no GitHub Pages, o endereço previsto é: https://jefersonalvesrs.github.io/HotelLux/ (verificar após o deploy).

## ✨ Funcionalidades

- Cinco páginas interligadas: Início, Acomodações, Experiências, Reservas e Contato
- Catálogo de três suítes com valores ilustrativos
- Galeria de experiências do hotel
- **Simulador de reservas** com validação de datas, hóspedes, capacidade das suítes e estimativa de preço
- Formulário demonstrativo com validação local
- Menu responsivo para dispositivos móveis
- Crédito do desenvolvedor no rodapé

## 🛠️ Tecnologias

HTML5, CSS3 (Grid, Flexbox e media queries), JavaScript e Google Fonts.

## 📸 Capturas de tela

Capturas de tela poderão ser adicionadas à pasta `screenshots/` após a publicação.

## 🚀 Executar localmente

Abra `index.html` no navegador ou use Live Server no VS Code. Não requer instalação de dependências.

## ⚠️ Imagens e observações

As fotografias utilizadas no site estão armazenadas localmente em `assets/images/`, em formato JPG. A foto original do banner inicial não foi enviada; provisoriamente foi usada a fotografia externa do hotel fornecida pelo usuário.

Projeto inteiramente fictício: não existe hotel real, disponibilidade, atendimento, reserva ou pagamento. O simulador e o formulário não enviam dados a servidores.

# HotelLux 🏨

Site institucional responsivo de um **hotel de luxo fictício**, desenvolvido com HTML5, CSS3 e JavaScript puro.

O projeto apresenta uma experiência visual sofisticada, com acomodações, experiências exclusivas e um simulador interativo de reservas.

## 🔗 Demonstração

🌐 **[Acessar o HotelLux](https://jefersonalvesrs.github.io/HotelLux/)**

📂 **[Repositório no GitHub](https://github.com/JefersonAlvesrs/HotelLux)**

## ✨ Funcionalidades

- Cinco páginas interligadas: Início, Acomodações, Experiências, Reservas e Contato.
- Layout responsivo para computadores, tablets e celulares.
- Menu de navegação adaptado para dispositivos móveis.
- Apresentação de três categorias de suítes com preços ilustrativos.
- Galeria de experiências, gastronomia e bem-estar.
- **Simulador de reservas** com:
  - Seleção de check-in e check-out.
  - Validação das datas informadas.
  - Seleção da quantidade de hóspedes.
  - Escolha da categoria de suíte.
  - Validação da capacidade das acomodações.
  - Cálculo estimado do valor total da estadia.
- Formulário de contato demonstrativo com validação local.
- Imagens armazenadas localmente no projeto.
- Crédito do desenvolvedor no rodapé.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura semântica das páginas.
- **CSS3:** estilização, Grid, Flexbox e media queries.
- **JavaScript:** interatividade, navegação e validações.
- **Google Fonts:** tipografia do projeto.
- **Git e GitHub:** versionamento do código.
- **GitHub Pages:** hospedagem gratuita.

## 🚀 Executar localmente

1. Clone o repositório:

   `git clone https://github.com/JefersonAlvesrs/HotelLux.git`

2. Abra a pasta `HotelLux` no Visual Studio Code.
3. Execute o arquivo `index.html` no navegador ou utilize a extensão Live Server.

**Não é necessário instalar dependências.**

## ⚠️ Observações

- O HotelLux é um projeto fictício desenvolvido para fins de portfólio.
- As fotografias utilizadas nas páginas estão armazenadas localmente em `assets/images/`.
- Os preços, acomodações e serviços apresentados são ilustrativos.
- O simulador não consulta disponibilidade real e não efetua reservas ou pagamentos.
- O formulário de contato funciona apenas como demonstração, sem envio de informações a servidores.
